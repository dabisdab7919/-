사진 추가하는 법
=================
이 폴더 안의 "프로젝트 이름 / 칸 이름" 폴더에 사진 파일(jpg, png, webp)을 넣으면
update-site 파일(윈도우: update-site.bat)을 실행했을 때 해당 슬라이드쇼 맨 뒤에 자동으로 추가됩니다.

- lead      : 맨 위의 큰 슬라이드쇼
- drawings, model, process ... : 아래 칸들 (폴더 이름이 곧 칸 이름)
- 순서는 파일 이름 순서입니다. 1.jpg, 2.jpg, 3.jpg 처럼 번호를 붙이면 편합니다.
- 사진은 가로 2400px 이하, 한 장 2MB 이하의 jpg를 권장합니다. (너무 크면 사이트가 느려집니다)
